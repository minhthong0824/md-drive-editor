Chính sách quyền riêng tư

Ghi chú Drive là ứng dụng web cá nhân để mở và sửa file .md trong Google Drive của chính bạn.

  • Ứng dụng chỉ xin quyền drive.file: chỉ truy cập các file bạn chọn trong hộp chọn file của Google.
  • Nội dung file chỉ đi giữa trình duyệt của bạn và Google Drive. Ứng dụng không có máy chủ, không thu thập, lưu trữ hay chia sẻ dữ liệu của bạn.
  • Trình duyệt lưu trên máy bạn: danh sách file gần đây, cài đặt giao diện và mã truy cập tạm thời. Xóa dữ liệu trang web để xóa các thông tin này.
  • Thu hồi quyền bất cứ lúc nào tại myaccount.google.com/permissions.

Liên hệ: mở issue tại GitHub của dự án.
